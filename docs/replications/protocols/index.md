# Article protocol evidence

This directory contains only the source-level evidence needed to interpret the
20 active reproduction cards. It records the primary article, an official
implementation when one exists, the registered protocol, and unresolved source
ambiguities.

These pages contain no ModSSC run, score, campaign verdict, scheduler record, or
recovered artifact. They cannot establish that an article result has been
reproduced. That decision is made only from a fresh, complete execution of the
corresponding cards.
