# JOSS checklist

## Repository

- [x] Repository is public
- [x] Repository has a clear open-source license
- [x] Repository has public issue tracking
- [x] Repository has sufficient public development history
- [x] Repository has installation instructions
- [x] Repository has user documentation
- [x] Repository has examples
- [x] Repository has tests or validation material
- [ ] Repository has a release suitable for review

## Paper

- [x] `paper/paper.md` exists
- [x] `paper/paper.bib` exists
- [x] Paper compiles to PDF
- [x] Paper length is roughly 750 to 1750 words
- [x] Paper has a Summary
- [x] Paper has a Statement of need
- [x] Paper explains the state of the field
- [x] Paper explains software design
- [x] Paper includes research impact
- [x] Paper includes AI usage disclosure
- [x] Citations resolve correctly
- [x] Figures resolve correctly

## Final acceptance step

- [ ] Create a tagged GitHub release after review
- [ ] Archive the accepted release on Zenodo, figshare, or equivalent
- [ ] Obtain an archive DOI
- [ ] Post the version number and archive DOI in the JOSS review issue
